# Kanavu Heritage

Welcome to the **Kanavu Heritage** repository! This is a PHP and MySQL-based web application designed to manage bookings, showcase property amenities, and provide a premium user experience for guests looking to stay at the heritage property.

## 🚀 Features

- **Interactive Calendar Booking:** An intuitive UI for guests to see available and booked dates.
- **Admin Dashboard:** Secure backend panel for administrators to manage bookings, track enquiries, and handle site content.
- **Responsive Design:** Optimized for seamless viewing on mobile, tablet, and desktop devices.
- **Custom Theming:** Elegant, dark-themed aesthetic with gold accents to match the premium heritage brand.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5, FullCalendar
- **Backend:** PHP 8+
- **Database:** MySQL

## 💻 Local Setup Instructions

To run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/manumarshel/kanavuheritage.git
   ```
2. **Move to local server environment:**
   Place the cloned folder inside your local web server's document root (e.g., `htdocs` for XAMPP).
3. **Database Configuration:**
   - Create a new MySQL database.
   - Update the connection credentials in `/includes/connect.php`.
4. **Run the app:**
   Navigate to `http://localhost/kanavuheritage` in your web browser.
